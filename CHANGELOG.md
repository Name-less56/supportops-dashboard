# Changelog

All notable changes are documented here. This project follows semantic versioning.

## [3.0.0] - 2026-11-06

### Added

- PostgreSQL authentication, sessions, password recovery and three scoped demo roles.
- Ticket analytics, filters, CSV export and administration of users, groups and categories.
- Professional Suite with Kanban, calendar, workload, customer, knowledge, automation, report, notification and security views.
- Ticket conversations, events, assignment, tags, SLA pause, escalation and bulk workflow actions.
- Governance settings stored in PostgreSQL.
- Jira-only integration demonstration with explicit no-connection notice.
- Privacy, terms, cookie controls, security documentation and automated CI.

### Security

- Bcrypt password hashes, hashed session/reset tokens, HttpOnly SameSite cookies, server-side RBAC, parameterized SQL and Helmet CSP.
